What's in the repository

FolderWhat it holdsWho uses it
specThe specification text: the record envelope, the store layout model, the seven record types, vocabularies, identifiers and versioningStandards and architecture teams
schemasJSON Schemas for the envelope and every record type, also browsable in the schema browserIntegration teams and vendors
examplesOne valid and one invalid record of each typeVendors building an adapter
validatoroiss-validate, which checks a vendor's records against the schemas before they reach a storeVendors and integration teams
adaptersRepresentative vendor exports and the adapters that map them to OISSVendors and integration teams
simThe synthetic grocery store that produces a day of OISS records for the demoAnyone evaluating OISS
webThis website, the demo store and the Store Operations AssistantAnyone evaluating OISS
docsThe RFC, design decisions and the deployment guideEveryone

Try it on your own computer

The demo runs on Node.js 22.18 or later, and the validator on Python 3.

git clone https://github.com/bcyong/oiss.git
cd oiss
npm install
npm run dev

To check records against the schemas:

python3 -m venv .venv && . .venv/bin/activate
pip install -e "validator[test]"
oiss-validate examples/valid

Take part

  • Comment on the RFC: the RFC is open for comment until January 15, 2027. Open an issue to comment.
  • Report a problem: open an issue for anything wrong in the specification, the schemas or the demo.
  • Build an adapter: start from the examples and the validator, and share the adapter for your feed.
